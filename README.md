# 🚀 ProMentor RUDN - Современный сайт программы менторства

Профессиональный веб-сайт для программы менторства студентов РУДН, созданный с использованием современных технологий и iOS-стиля анимаций.

## ✨ Особенности

- 🎨 **Современный дизайн** с glassmorphism эффектами и градиентами
- 💫 **Плавные анимации** в стиле iOS (Framer Motion)
- 📱 **Полностью адаптивный** дизайн для всех устройств
- 🌙 **Темная тема** с автоматическим определением системных настроек
- ⚡ **Высокая производительность** благодаря Vite
- 🎯 **SEO оптимизация** с мета-тегами
- 🔥 **TypeScript** для типобезопасности

## 🛠️ Технологический стек

- **Frontend Framework:** React 18+
- **Build Tool:** Vite
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS 3+
- **Анимации:** Framer Motion
- **Иконки:** Lucide React
- **Формы:** React Hook Form
- **Счетчики:** React CountUp
- **Intersection Observer:** React Intersection Observer

## 📦 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn

### Быстрый старт

1. **Клонировать репозиторий:**
```bash
git clone <repository-url>
cd amina_rudn
```

2. **Установить зависимости:**
```bash
npm install
```

3. **Запустить dev-сервер:**
```bash
npm run dev
```

Сайт будет доступен по адресу: `http://localhost:5173/`

### Другие команды

```bash
# Сборка для продакшена
npm run build

# Preview продакшен-сборки
npm run preview

# Линтинг кода
npm run lint
```

## 🎨 Дизайн-система

### Цветовая палитра

- **Primary (Синий):** `#1E3A8A` - образование, надежность
- **Secondary (Оранжевый):** `#F97316` - энергия, прогресс
- **Accent (Золотой):** `#FBBF24` - достижения, успех

### Ключевые компоненты

- **Glassmorphism** эффекты для модернового вида
- **Градиентные** фоны и текст
- **Анимированные счетчики** для статистики
- **Интерактивный Timeline** с этапами программы
- **FAQ секция** с аккордеонами
- **Адаптивная навигация** с мобильным меню
